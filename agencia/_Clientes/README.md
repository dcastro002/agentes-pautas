# Clientes

Una carpeta por cliente, con la misma estructura que el contexto de la agencia:

```
_Clientes/
└── <cliente>/
    ├── Estrategia.md      ← misma estructura que _Context/Estrategia.md
    ├── BrandKIT/
    │   ├── Diseno.md      ← misma estructura que _BrandKIT/Diseno.md
    │   └── logos/
    └── Cuentas.md         ← IDs de cuenta publicitaria, página, píxel, moneda, tablero de Monday, portal de HubSpot (sin contraseñas ni tokens)
```

- Nombre de carpeta en minúsculas y con guiones: `grupo-avandaro`, `cefat`.
- Para un entregable de cliente, su contexto **reemplaza** al de la agencia.
- Nunca guardar aquí credenciales, tokens ni bases de datos con datos personales.
