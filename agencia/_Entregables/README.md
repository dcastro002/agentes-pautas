# Entregables

Aquí escriben los agentes. Estructura: `_Entregables/<cliente>/<AAAA-MM>/`.

Nombre de archivo: `<AAAA-MM-DD>_<tipo>_<tema>_<etapa>.<ext>`

| Etapa | Lo genera |
|---|---|
| `brief` | estratega |
| `copy_v1`, `copy_v2`… | redactor |
| `diseno` (.md, .html o .svg) | disenador |
| `revision_v1`, `revision_v2`… | guardian-marca |
| `reporte_<alcance>` | analista |
| `campana_<tema>` | operador-pauta |
| `..._aprobado` | se agrega al aprobar una persona |

Para la marca propia, `<cliente>` es `agencia`.
